## 本地预览

在仓库目录运行 `python3 -m http.server 8000`，访问 http://localhost:8000 。

## 参与协作

可在 Issues 提交修改建议，或 Fork 本仓库、修改后提交 Pull Request。活动内容在 index.html，响应式样式在 style.css。合并到 main 后，GitHub Pages 自动更新。请勿提交内部筹备文件、受邀人员名单或未经授权的联系方式。

## 内容依据

采用 2026 年 11 月 20 日 v4 官网设计稿和组委会提供的新版标识。议程沿用草案，嘉宾、报名及票务以组委会后续确认为准。[设计参考 CASPA CEO Summit](https://caspaceosummit.com/)
